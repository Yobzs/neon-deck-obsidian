# Neon Deck 2.1.2 — release notes

Released 11 Nov 2026. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Don't replace the whole `neon-deck` folder: it also holds your settings and module data.

## New
- **Flashcards off the page (#56):** new cards are kept in a hidden `neon-cards` block at the end of the note. They stay in the file but don't show in reading view, Live Preview or PDF. Study notes get an accent **cards button** in the top-right toolbar with the card count. It opens Add flashcard, Add exercise, Show cards (list, edit, delete) and Quiz this note. Existing `question :: answer` lines keep working, and the card popup can move them off the page with quiz history kept.
- **Exercises (#56):** `question ::: answer`. In the quiz you type your answer first, then see the expected answer with Match / Different and grade as usual.
- **Start day asks when the day started (#57):** pre-filled with now; `845`, `8:45` and `8.45` all work.
- **Drop folders into Cards (#55):** a folder from your computer comes in with everything inside it. Its images stay in that folder.

## Better
- **Tickets sort by status by default (#59):** Not started, Waiting, In progress, Open, Done. Due date is still in the dropdown.
- **Follow-ups (#58):** opening a ticket whose follow-up is due counts as following up. The next follow-up moves ahead by your "follow up after" days.

## Fixed
- **Workday time in totals (#54):** the dashboard's time worked and the Time tab's week bars now include the Start day → End day timer.
- **Folder counts (#53):** folder cards and the Cards sidebar count images and other files, not only notes.

## Verification
30 unit tests pass and the bug script reports no failures. Every change was checked in the test vault through Obsidian's debugging interface, including the quiz with real key presses. The plugin remains 100% offline and local.
