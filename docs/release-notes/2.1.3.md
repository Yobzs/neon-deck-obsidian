# Neon Deck 2.1.3 — release notes

Released 12 Nov 2026. To update, replace `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/neon-deck/` (keep the folder: it holds your module data), or unzip `neon-deck.zip` into `.obsidian/plugins/`.

## Community plugin readiness
- **No default hotkeys:** Quick capture no longer ships with Mod+Shift+Space; set your own in *Settings → Hotkeys*. Upgrading from 1.x no longer writes hotkeys for you.
- **Leaner start:** the old 1.x font loader is gone (fonts are inside `styles.css`).
- **Release tags** now match the manifest version exactly (`2.1.3`, no `v`), as the community plugin list requires.

## Verification
30 unit tests pass and static checks report no failures.
