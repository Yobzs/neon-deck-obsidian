# Neon Deck 2.1.4 — release notes

Released 12 Nov 2026. To update, replace `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/neon-deck/` (keep the folder: it holds your module data), or unzip `neon-deck.zip` into `.obsidian/plugins/`.

## Community plugin readiness
- **Public API only:** modules find each other inside the plugin, daily-note settings are read from Obsidian's `daily-notes.json`, search opens through the Search view, and the old 1.x plugin check reads `community-plugins.json`.
- **Light / dark toggle removed:** Neon follows Obsidian's mode; use Obsidian's *Toggle light/dark mode* command.
- **Tidy into Core** no longer edits Obsidian's Daily notes / Templates settings; it tells you what to change.
- **No default hotkeys** (since 2.1.3): set Quick capture's in *Settings → Hotkeys*.

## Verification
30 unit tests pass, static checks report no failures, and the changed flows were checked in the test vault.
