# Neon Deck 2.2.1 — release notes

Released 14 Nov 2026. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Since this version your module data is also kept in `.obsidian/neon-deck-data/`, so replacing the whole folder no longer loses it.

## Back to the uncluttered 2.1.2 (#64, #62, #63)
- The 2.1.3–2.2.0 changes are gone again: no Pin board / Dynamic Island, and the community-store rework is undone. Only the smooth drags from 2.2.0 came back (see below).

## New
- **Sidebar tree (#76):** a list/tree button in the sidebar header. Folders open in place, up to 3 levels deep; a folder on the 3rd level opens like in the flat list.
- **Quick save (#61):** a new Quick capture target for numbers and bits of info you need today. They're listed under the Quick capture box: click to copy, × to remove. The list starts empty every day.
- **Links in tasks work:** `[[note]]`, `[[note|alias]]` and `[text](note.md)` in tasks and global tasks are links: click opens the note (Ctrl: new tab), hover shows the preview. Handy after dragging a note into the add box.
- **Delete tasks (#71):** × on a task row (on hover) removes the line from its note, with Undo.
- **Note transitions:** notes fade in when you switch notes or switch to a note's tab (off with *Reduce motion*).

## Better
- **Pinned notes (#65, #68):** notes starting with `!` sit above the folders in the sidebar, and pinned notes and folders have their own gold colour.
- **Page breaks (#74):** clicking one in Live Preview no longer opens its HTML; use the arrow keys to reach and delete it.
- **Images (#69):** `.gif`, `.webp`, `.svg`, `.bmp` and `.avif` also move to `Core/Images`.
- **Smooth drags (#66):** Obsidian's drag label keeps following the mouse over Neon folders.
- **Cards follow a moved folder (#72):** moving the folder you are in no longer jumps back to the vault root.
- **README:** shorter, with a TL;DR at the bottom (#70).

## Fixed
- **Callout lock after an update (#67):** unlocking was refused until the note re-rendered; the lock also works in popouts, hover previews and canvas now.
- **Module data survives a replaced plugin folder (#73):** a missing `data.json` (research list, settings, time…) is restored from `.obsidian/neon-deck-data/`.

## Verification
31 unit tests pass, the bug script reports no failures, and the all-commands run in the test vault shows no errors. Every change was checked in the test vault through Obsidian's debugging interface. The plugin remains 100% offline and local.
