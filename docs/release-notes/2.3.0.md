# Neon Deck 2.3.0 — release notes

Released 16 Nov 2026. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Your module data stays where it is.

## New
- **Ticket widget views (#77):** the Tickets card switches between **Open**, **Waiting / follow-ups** and **Needs attention** (the same rule as reminders). Small ticks at the top show the views, the active one is an accent dot; click a tick, scroll over the card header, or use Left/Right. A hidden view's tick pulses when it has overdue or follow-up tickets. Each view has its own count and the card remembers the last one. Reminders keep running whatever view is shown.
- **Progress widget (#78):** Tasks and Global tasks are now one Tasks card with two views, and the freed slot holds **Progress**: type a goal, click or drag along its bar to set how far along it is (steps of 5%), click the date chip for a due date (overdue dates turn red), × deletes with Undo. Goals are also written to the Global tasks backup note under `## Progress`.
- **Reorder pinned notes (#80):** drag a `!` note above or below another one in the sidebar. The order is saved in the plugin data (no files are renamed) and the main card view uses it too.
- **Go to root (#84):** a home button next to *Up a folder* in the card view and the sidebar. Drop cards on it to move them to the vault root.

## Better
- **Pinned folders as tiles (#83):** pinned folders in the sidebar are a compact grid: icon, name (up to two lines, full path on hover) and a count badge.
- **Weekly time (#81):** the dashboard totals tile shows time worked **this week** (from Monday), with the month and balance below.
- **Ticket log split (#82):** the ticket view shows **Log** (steps done, time, your own lines) and **Changes** (status, priority, due date, reminders, edits) separately. Notes are unchanged, so old tickets split on their own.

## Cleanup (#79)
- The concept graph (hidden since 1.6) and its "Hide as stop-word" menu item are gone; the notes graph is unchanged.
- Shared helpers replace duplicated date and folder code, and fallback styles that were included three times are included once. About 200 lines less.

## Verification
36 unit tests pass and the bug script reports no failures. Every change was checked in the test vault through Obsidian's debugging interface: pane switching (click, wheel, saved choice), the three ticket views with real tickets, progress bar clicks and drags with real mouse input, pinned-note reordering, renames and deletes, five plugin reloads without duplicate cards or errors. The plugin remains 100% offline and local.
