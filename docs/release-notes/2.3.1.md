# Neon Deck 2.3.1 — release notes

Released 24 Nov 2026. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Your module data stays where it is.

## New
- **Goals tab (#85, #89):** the Progress widget is replaced by a **Goals** tab (dashboard top bar, sidebar, or the command *Open Goals*). Instead of a percent bar, you **Check in** on the days you work on a goal, with an optional one-line note (once per day; checking in again edits the note; Undo after each check-in). Each goal shows a 12-week strip of check-in days, your current streak, the last check-in and its notes. Click the name to rename it, the date chip for a due date (overdue turns accent), ✓ to mark it done (it moves to a Done group, ↺ reopens), × to delete with Undo.
- **Your Progress items move over on their own:** each becomes a goal with its name and due date; a percent above 0 becomes a first check-in ("40% (from Progress)"), 100% becomes a done goal.
- **Copy a ticket number (#90):** click the number in the ticket header, or use *Copy ticket number* in a ticket's right-click menu.

## Better
- **Global tasks has its own card again (#89):** back in the slot Progress used; the Tasks card is one list again.
- **Hidden flashcards stay hidden (#87):** in Live Preview the cursor hops over the hidden `neon-cards` block, so its source no longer shows up when you arrow to the bottom of a note.
- **Deleting flashcards is instant (#86):** the card disappears on click and the list redraws right away, also while the note is open (it used to wait about 2 seconds for the editor to save). Adding and editing cards are quicker too.

## Good to know
- The Global tasks backup note now lists goals under `## Goals`. Restoring from that note brings back Global tasks only, not goals.

## Verification
38 unit tests pass and the bug script reports no failures. Every change was checked in the test vault through Obsidian's debugging interface: the Progress-to-Goals migration from saved 2.3.0 data, adding, checking in (with note), undo, done, reopen and delete with undo, the backup note, the cursor hop with real arrow keys, flashcard delete with the note open, ticket number copy, and a run of every command without errors. The plugin remains 100% offline and local.
