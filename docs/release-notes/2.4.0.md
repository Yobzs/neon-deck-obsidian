# Neon Deck 2.4.0 — release notes

Released 24 Nov 2026. Same code as 2.3.2; the version number now marks the features added in 2.3.1 and 2.3.2 (Goals tab, resizable table columns). If you run 2.3.2, nothing changes. **To update, copy only `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/neon-deck/`.** Your module data stays where it is.

## New
- **Goals tab (from 2.3.1, #85, #89):** goals with daily check-ins (optional note) replace the Progress widget; your Progress items moved over on their own. Global tasks has its own dashboard card again.
- **Resizable table columns (#92):** hover a table header and drag the thin line at the right edge of a column to make it wider or narrower; double-click the line to reset the table. Works in Live Preview and Reading view, and editing cells keeps your widths. Widths are saved in the plugin (per note and per header row), so your notes stay plain markdown; they follow renames of the note or its folder. Changing a table's header text or number of columns resets its widths.

## Better
- **Goals tab, cleaner look:** the header matches the other tabs, with four small tiles (checked in today, this week, best streak, done). Goals are calm rows instead of boxes inside a box. A round button on the left checks in for today (it fills once you have; click again to edit the note). Rename, due date, done and delete are in the ⋯ menu or on right-click. Done goals are compact rows.
- **Check-ins as a timeline:** each goal shows its last 28 days as a row of bars, today on the right, with small gaps between weeks. Hover a bar for the date and note. It replaces the 12-week grid.
- **Narrow panes:** the Goals tab follows the width of its pane: the tiles wrap two by two and the timeline moves under the goal's name.

## Verification
39 unit tests pass and the bug script reports no failures. Checked in the test vault through Obsidian's debugging interface: column drags with real mouse input in Live Preview and Reading view, widths after reopening, editing a cell, renaming the note and resetting; the Goals tab wide and at 400 px (no sideways scrolling), adding, checking in with a note, undo, done and delete from the menu; and a run of every command without errors. The plugin remains 100% offline and local.
